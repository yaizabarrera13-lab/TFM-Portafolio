# 🧠**Predicción de Diabetes Tipo II con Machine Learning**
## **Descripción del proyecto**
La *diabetes mellitus* tipo II es una enfermedad crónica que representa uno de los principales retos actualmente en la salud pública, tanto por su elevada prevalencia como por su impacto en el gasto sanitario.
La detección temprana de la enfermedad es fundamental para prevenir complicaciones graves. Sin embargo, los sistemas de cribado tradicionales presentan limitaciones en la detección precoz y eficiente de los casos de riesgo. 
En este contexto, este proyecto explora el uso de técnicas de *Machine Learning* para mejorar la detección precoz de la enfermedad. 
_________________________________________________________________________________________

## 🎯**Objetivo**
Desarrollar y evaluar un modelo de clasificación supervisada para la predicción de diabetes mellitus tipo II en mujeres, a partir de variables clínicas, utilizando el dataset *Pima Indians Diabetes Database*.
_________________________________________________________________________________________

## ⁉️**Preguntas de Investigación**
1. ¿Es posible predecir la presencia de diabetes a partir de variables clínicas básicas con un rendimiento suficiente para el apoyo a la decisión clínica?
2. ¿Qué algoritmo de aprendizaje automático ofrece mejor sensibilidad en la detección de casos positivos, minimizando falsos negativos?
3. ¿Qué variables clínicas presentan mayor capacidad predictiva y dichas variables son coherentes con la evidencia clínica?
